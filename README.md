# THE FIRST SHIFT
Your first day at Northline Renewables, a fictional EPC contractor building renewable natural gas facilities.

## Start here
Create a Claude project. Upload identity.md, rules.md, examples.md and every Markdown file in reference/. Paste rules.md and identity.md into project instructions if available. Preserve filenames. Start a new conversation with: **It's my first day as a project engineer. Where do I start?**

No integrations, credentials or paid infrastructure required beyond access to the chosen AI service. This is a fictional training environment, not an actual company handbook. The tests folder is for evaluators, not agent context.

Your first-day win: locate the current project documents and prepare one internal equipment-register update for mentor review. You do not need to issue anything externally.

If the assistant invents information, stop and ask for its source. See tests/acceptance.md for evaluation.
